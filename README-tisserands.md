# Les Tisserands

**La plateforme d'aide aux réfugiés en France.**
Droits, apprentissage, entrepreneuriat, culture : relier ceux qui arrivent et
ceux qui sont là.

🔗 **[les-tisserands.org](https://www.les-tisserands.org)** — en ligne, Nancy

---

## Le problème

Une personne qui arrive en France doit comprendre ses droits, apprendre la
langue, trouver des interlocuteurs — le tout dans une langue qu'elle ne maîtrise
pas encore, avec une information dispersée entre associations, administrations et
bouche-à-oreille. Les ressources existent ; le chemin pour les atteindre, non.

Les Tisserands rassemble cette information, la rend disponible dans la langue de
l'arrivant, et la relie à ce qui se passe réellement sur le territoire.

## Ce que fait la plateforme

- **Assistant juridique** — réponses aux questions de droit, dans la langue de
  l'utilisateur (API Claude)
- **Partages** — ce qui se passe près de chez soi : cours de FLE, tandems
  linguistiques, événements culturels, initiatives associatives
- **Trajectoires** — les parcours de personnes arrivées avant, de l'ingénieur
  afghan au traiteur congolais : montrer que le chemin existe
- **Carte des ressources** — les points d'appui du territoire nancéien

Interface disponible en français, anglais, arabe, ukrainien, dari, espagnol et
allemand.

## Stack

Ruby on Rails 7.2 · PostgreSQL · API Claude (assistant juridique multilingue) ·
cartographie interactive · internationalisation 7 langues

## Statut

Projet citoyen à impact social, open source, développé à Nancy.
